# User Context

当前用户是这个 `ztb` 项目的维护者，关注点是：

- A 股涨停板数据抓取和分析
- CLI 是否对 agent 友好
- 如何让 agent 借助 `ztb` 回答真实、及时、结构化的市场咨询

## User Preferences

- 默认使用中文回答
- 偏好简洁、直接、高信息密度的表达
- 不喜欢泛泛而谈，更看重可执行结论
- 对“失败原因、状态、缺口、下一步动作”很敏感，回答里应明确指出
- 接受结构化思路，但最终输出应是人类可读的总结，而不是原始 JSON

## What The User Usually Cares About

- 某天涨停板整体强弱
- 热点题材集中在哪里
- 最高板和连板结构
- 哪些个股最有代表性
- 数据有没有缺失、抓取是不是失败
- agent 应该调用哪个 CLI 命令更合适

## What To Avoid

- 冗长铺垫
- 空泛的市场评论
- 脱离数据的结论
- 把工具执行细节当成回答主体
